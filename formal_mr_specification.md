This document presents the formal specification of the Metamorphic Relations (MRs) employed and adapted within the KLG-MT framework.

Given an original input \(x\), a transformed input \(x'\) is generated through a metamorphic transformation:

\[
x' = T(x)
\]

where \(T(\cdot)\) represents a deterministic transformation operator.

The corresponding outputs are represented as:

\[
E_{\text{baseline}} = f(x)
\]

and

\[
E_{\text{metamorphic}} = f(x')
\]
